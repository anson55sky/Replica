## 项目简介

Replica 是一款面向 macOS 的轻量应用克隆工具。它可以复制任意 `.app`，自动生成独立的 Bundle ID、隔离会话与数据目录，让多个分身（如多个微信、多个 Telegram）在同一台 Mac 上并存运行。

## 核心功能

- **一键克隆**：拖入或选择源 App，自动生成独立 Bundle ID 的分身。
- **完全隔离**：每个分身拥有唯一 Bundle ID、独立的会话密钥与用户数据目录（Telegram / Discord 已适配），互不覆盖。
- **URL Scheme 隔离**：自动改写分身的自定义协议（`tg://`、`discord://`、`vscode://` 等），分身与原版不抢同一个链接协议。
- **本地化显示**：分身库与常用应用均显示中文名（微信 而非 WeChat）。
- **自定义常用应用**：侧边栏常用应用可自由增删，设置持久化。
- **默认落入 `~/Applications`**：克隆完成即在启动台显示，无需手动移动。
- **自动检查更新**：内置更新检测，必要时强制更新。

## 系统要求

- macOS 12.0 或更高版本
- Apple Silicon 或 Intel（通用二进制）
- 约 20 MB 磁盘空间

## 安装教程

1. 前往 [最新版下载](https://github.com/anson55sky/Replica-Releases/latest)，下载 `Replica.dmg`。
2. 打开 DMG，将 `Replica.app` 拖入「应用程序」文件夹。
3. 首次打开若提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。
4. 启动 Replica，开始克隆。

## 使用说明

1. 在左侧「克隆」页，将想要克隆的 App 拖入虚线框，或点击虚线框 / 「选择…」按钮选取。
2. 确认源 App、Bundle ID、分身名称无误后，点击「开始克隆」。
3. 克隆完成后分身会自动出现在「应用程序」与启动台；在「分身库」可查看克隆记录与删除分身。
4. 侧边栏「常用应用」点击「编辑」可自定义常用列表。
5. 「设置」中可切换中英文、深浅色主题、检查更新。

## 常见问题

- **克隆的应用能放进系统「应用程序」吗？**
  可以。Replica 已为每个分身分配唯一 Bundle ID，启动台会显示为独立图标，不会与原版冲突。
- **分身之间会共享登录状态吗？**
  不会。分身拥有独立的会话密钥与数据目录。
- **点击 `tg://` 这类链接会打开哪个？**
  链接默认打开原版；分身使用改写后的独立协议，互不抢占。
- **克隆后打不开？**
  多为 Gatekeeper 拦截，见「安装教程」第 3 步。
- **支持哪些 App？**
  通用 App、Electron 系（VS Code、Discord 等）、Telegram、微信、QQ 等均已适配；部分强签名 / 公证 App 的个别功能（如 App Group 共享）在分身中可能不可用。
